Overview
A responsive personal portfolio built to present my technical skills,
software projects, internship experience, academic background,
certifications, and contact information.
The website features a modern dark-first interface with an optional
light theme, interactive project and internship showcases, and a contact
form for professional enquiries.
Highlights
Responsive layouts for desktop, laptop, tablet, and mobile
Dark and light theme switching
Smooth-scrolling navigation with active-section highlighting
Scroll-triggered reveal animations and interactive hover effects
Horizontally draggable project and internship card sections
Technical skills grouped by programming, tools, core competencies,
and soft skills
Dedicated sections for projects, internships, education, and
certifications
Contact form with email delivery through FormSubmit
Mobile navigation menu and animated message-success feedback
