# Rahul R U — Personal Portfolio

A responsive personal portfolio website designed to showcase my skills, projects, internship experience, education, certifications, and professional contact information.

## 🌐 Portfolio

The portfolio presents my technical background and provides recruiters and visitors with an easy way to explore my work and contact me.

---

## ✨ Features

- Responsive portfolio design for desktop, tablet, and mobile
- Modern dark and light theme support
- Smooth scrolling navigation
- Active navigation highlighting based on the current section
- Animated section and card reveal effects
- Interactive hover effects on cards and technology badges
- Professional hero/home section with profile image
- Technical skills categorized into different areas
- Project showcase with technologies used
- Internship experience section
- Education section with institution images and external links
- Certification showcase
- Contact form with email delivery
- Animated "Message Delivered!" success popup
- Mobile-friendly navigation menu
